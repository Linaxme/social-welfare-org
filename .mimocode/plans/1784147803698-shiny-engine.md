# Plan: Add English Language Support to Somiti App

## Overview
The app currently has only Bengali (bn) UI strings hardcoded across ~20 files (335+ instances). We need to add English (en) support with a language switcher in settings.

## Approach: LocaleProvider + AppStrings (no code generation)

Instead of Flutter's `gen_l10n` / `.arb` approach (which requires `context` everywhere), we'll use a simpler pattern that matches the existing `ThemeProvider` singleton:

1. **`LocaleProvider`** — singleton `ChangeNotifier` (like `ThemeProvider`) that holds the current locale, persists to SharedPreferences, and notifies listeners
2. **`AppStrings`** — static class with all UI strings, keyed by locale, accessed via `AppStrings.current.xxx`
3. When locale changes → `LocaleProvider` notifies → `app.dart`'s `ListenableBuilder` rebuilds → all `AppStrings.current.xxx` calls return the new language

This works without `BuildContext`, so PDF generation, validators, and formatters all get translations naturally.

## Files to Create

### 1. `lib/shared/data/locale_provider.dart`
- Singleton pattern matching `ThemeProvider`
- Stores `Locale('bn')` as default
- Persists to `SharedPreferences` under key `'locale'`
- Exposes `currentLocale`, `setLocale(Locale)`, `isBn`, `isEn`

### 2. `lib/core/l10n/app_strings.dart`
- Static class with all translated strings organized by category
- `AppStrings.current` returns the correct map based on `LocaleProvider.instance.currentLocale`
- Categories: common, auth, dashboard, members, collections, help, reports, settings, profile, validators, receipt, export
